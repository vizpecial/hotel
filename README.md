# 🏨 Hotel Booking Manager

A full-stack hotel reservation and management web application built with **Spring Boot**, **Thymeleaf**, **Spring Data JPA**, and an in-memory **H2 Database**.

🌐  [**Live Demo**](https://hotel-booking-manager-2tv2.onrender.com)

---

## 🚀 Tech Stack
* **Backend:** Java, Spring Boot, Spring Data JPA, Maven
* **Frontend:** Thymeleaf, HTML5, CSS3, JavaScript
* **Database:** H2 Database (In-Memory)
* **Deployment & Containerization:** Docker, Render

---

## ✨ Features
* **Hotel Stay Booking:** Streamlined user interface to book hotel stays effortlessly.
* **Reservation Dashboard:** View, track, and manage active bookings in real time with details including:
  * Check-In & Check-Out dates
  * Total duration of stay
  * Quick management actions
* **Cloud-Native Compatibility:** Fully containerized with Docker and configured to adapt to dynamic cloud server ports (`${PORT:8008}`).
